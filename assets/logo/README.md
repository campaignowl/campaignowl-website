# Campaign Owl logo pack

All generated from the master `logo.svg` in the app repo (`app/public/logo.svg`).
Regenerate at any size from that SVG — never scale up a small PNG.

## Google Ads (business logo assets — no text, solid background)

| File | Size | Where it goes |
|---|---|---|
| `google-ads-logo-square-1200x1200.png` | 1200×1200 (1:1) | Google Ads → Assets → Logo (square). Min accepted 128×128 |
| `google-ads-logo-landscape-1200x300.png` | 1200×300 (4:1) | Google Ads → Assets → Logo (landscape). Min accepted 512×128 |

Both are full-bleed solid cream (#FEF3C7) with no transparency and no text,
per Google's logo asset guidance. Well under the 5MB limit.

## Website / favicons / general use (rounded cream square, transparent corners)

| File | Use |
|---|---|
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | Browser tab icons |
| `apple-touch-icon-180.png` | iOS home-screen icon |
| `logo-64/128/192/256/512/1024.png` | Anything else — email signatures, directories, social profiles, press. Pick the nearest size UP and let it scale down |
